# 更酷炫的黑袍饰品

这是 homelander_maomao 的独立 Curios 饰品附属模组。本版扩展到 45 件饰品，按 T1-T5 明确分级：低阶以稳定数值为主，高阶才加入少量机制。

## 分级逻辑

- T1 入门：轻量生命、护甲、速度或伤害补正。
- T2 实战：更明显的单项专精，适合早中期搭配。
- T3 精锐：混合型数值提升，开始出现少量保护机制。
- T4 传奇：高额数值与角色主题饰品，部分需要灾变材料。
- T5 原型：少量机制型饰品，例如时序脉冲、相位踏步、沸血、伺服护盾。
