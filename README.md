# BlockForge Studio

一个面向 Minecraft Forge 模组开发的桌面编辑器，主打可视化、中文化和 AI 辅助。

它把项目创建、元素编辑、贴图绘制、节点逻辑、GUI 设计、Forge 生成、Gradle 构建和本地 AI 对话放在同一个工作台里，让模组制作更像在用一套完整的桌面软件，而不是零散地拼工具。

## 主要能力

- 项目创建与打开
- 物品、方块、配方、战利品表、`mcfunction` 编辑
- 内置像素绘制器与独立贴图编辑窗口
- 节点逻辑编辑、变量、NBT、事件模板
- 可视化 GUI 草图
- Forge 1.20.1 工程生成与本地构建
- 构建前快照、日志与导出
- Ollama、LM Studio、DeepSeek 等 AI 接入

## 适合什么场景

- 想做一个中文友好的模组编辑器
- 想把常见模组制作流程集中到一个桌面应用里
- 想用节点图和表单一起做玩法逻辑
- 想快速生成 Forge 工程并查看构建结果

## 启动

```bash
npm install
npm run dev
```

或者直接启动桌面版：

```bash
npm run start
```

## 说明

- 默认面向 Forge 工作流
- Fabric 目前保留结构，但未作为首版重点
- AI 草案与工程大改都会先经过校验和确认
